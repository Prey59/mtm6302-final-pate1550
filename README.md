# STH Lash Co.

## Project Information

- Developer: Patel Prey
- Course: MTM6302 – Web Development III
- Milestone: 2 – Application Plan and Architecture

## Project Description

STH Lash Co. is a responsive web application designed to help customers explore lash services, view pricing, request appointments, contact the studio, and submit customer reviews.

## Core Features

- F1: Lash Services and Pricing
- F2: Appointment Booking and Confirmation
- F3: Contact Form
- F4: Customer Reviews and Ratings
